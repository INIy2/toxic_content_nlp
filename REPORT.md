# Отчёт по классификации текстовых сообщений

## 1. Датасет

Для эксперимента использовался датасет Toxic Russian Comments (комментарии из OK.ru). Дополнительно в обучение добавлены нейтральные пересказы из RuParaDetox.

Исходные метки переведены в три класса: токсичное, оскорбительное, нейтральное.

### Покрытие и состав

После очистки осталось 249826 текстов:

| Выборка | Нейтральные | Оскорбительные | Токсичные | Всего |
|---|---:|---:|---:|---:|
| train | 164762 | 22530 | 12539 | 199831 |
| val | 20614 | 2816 | 1567 | 24997 |
| test | 20614 | 2816 | 1568 | 24998 |

Сообщения в основном короткие:

- средняя длина около 12 слов;
- медиана 8 слов.

При темпе речи около 2,5 слова в секунду это примерно 5 секунд, что соответствует обычному голосовому сообщению.

### Качество данных

Около 3,6% текстов содержали шум: латинские буквы внутри русских слов, растянутые буквы, замаскированный мат, объявления с телефонами. После очистки удалено 3,9% строк.

Для проверки разметки вручную просмотрено 300 случайных комментариев. Совпадение с разметкой датасета составило 86%, каппа Коэна 0,79.

### Качество транскрипций

Исходные данные текстовые. Для распознавания голосовых сообщений используется Whisper large-v3-turbo.

Качество распознавания проверено на 600 записях из датасета Golos:

- WER на записях с телефона: 16,2%;
- WER на записях с дальнего микрофона: 15,5%.

Также 300 комментариев из тестовой выборки были озвучены с помощью TTS и распознаны обратно. WER составил 13,2%, мат сохранился в 96% случаев.

## 2. Предобработка данных

Перед классификацией была выполнена нормализация текста:

- текст приведён к нижнему регистру;
- удалены ссылки, упоминания, эмодзи и пунктуация;
- латинские буквы внутри русских слов заменены на русские;
- удалены объявления с телефонами и ссылками;
- удалены дубликаты и тексты с конфликтующими метками.

Текст приводится к такому виду, в котором его выдаёт распознавание речи.

## 3. Метод классификации

Использован ансамбль из пяти моделей без трансформеров:

- TF-IDF + Logistic Regression;
- TF-IDF + LinearSVC;
- TF-IDF + Complement Naive Bayes;
- TextCNN на эмбеддингах navec;
- BiGRU на эмбеддингах navec.

Для TF-IDF использовались словные n-граммы (1, 2) и символьные n-граммы (2, 5).

### Почему выбран этот метод

TF-IDF хорошо подходит для коротких текстов, потому что токсичность в основном выражается конкретными словами.

Символьные n-граммы помогают учитывать опечатки и разные варианты написания мата.

Нейросети на эмбеддингах лучше учитывают синонимы и короткие фразы.

Модели ошибаются по-разному, поэтому их объединение работает лучше, чем каждая модель отдельно.

Классы несбалансированы, поэтому при обучении использовались веса классов.

## 4. Результаты

| Модель | Accuracy | Macro F1 |
|---|---:|---:|
| TF-IDF + Complement NB | 91,5% | 0,809 |
| BiGRU | 94,9% | 0,868 |
| TextCNN | 95,5% | 0,881 |
| TF-IDF + Logistic Regression | 96,3% | 0,897 |
| TF-IDF + LinearSVC | 96,4% | 0,898 |
| Ансамбль | 96,7% | 0,905 |

Веса моделей подбирались на валидационной выборке. Лучшие веса:

- LinearSVC: 0,41;
- Logistic Regression: 0,30;
- TextCNN: 0,22;
- Complement NB: 0,07.

Итоговая точность ансамбля на тестовой выборке: 96,7%.

## 5. Обработка после классификации

Добавлена метка "сомнительно". Если уверенность модели ниже 0,69, сообщение не классифицируется автоматически.

Порог подобран на валидационной выборке. На тестовой выборке:

- сомнительными помечено 4,8% сообщений;
- в них попало 53% всех ошибок;
- Macro F1 на остальных сообщениях вырос с 0,905 до 0,944.

## 6. Анализ ошибок

На тестовой выборке неправильно классифицировано 838 из 24998 сообщений.

| Истинный класс | Предсказанный класс | Количество |
|---|---|---:|
| оскорбительное | нейтральное | 238 |
| токсичное | оскорбительное | 174 |
| оскорбительное | токсичное | 149 |
| нейтральное | оскорбительное | 148 |
| токсичное | нейтральное | 76 |
| нейтральное | токсичное | 53 |

Самой сложной оказалась граница между оскорбительными и токсичными сообщениями. Модель ориентируется на отдельные слова, поэтому угроза без явных слов про насилие часто определяется как оскорбление.

Также ошибки возникают:

- на искажённом мате и редких оскорблениях;
- на словах с двойным смыслом, например "тварь" или "козлы" про животных;
- на очень коротких сообщениях.

Среди уверенных ошибок модели часть приходится на неточную разметку датасета.

Отдельно замечено, что фразы с матом без оскорбления, например "б**, опять автобус ушёл", модель часто считает оскорбительными.

## 7. Вывод

Реализована классификация текстовых сообщений: подготовка данных, предобработка, обучение моделей, ансамбль, обработка после классификации и анализ ошибок.

Лучшая отдельная модель (LinearSVC) показала точность 96,4%, ансамбль из пяти моделей 96,7%.
