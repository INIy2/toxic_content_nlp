## Кейс 5

Обнаружение токсичного контента: Классификация комментариев как токсичных, оскорбительных или нейтральных.

Сообщения делятся на три класса:

1. Токсичные: угрозы, агрессия, пожелания смерти.
2. Оскорбительные: оскорбления без явной угрозы.
3. Нейтральные: без токсичности и оскорблений.

Голосовое сообщение переводится в текст с помощью Whisper, затем текст классифицируется.

## Датасеты

### Toxic Russian Comments

Основной датасет. Комментарии из социальной сети OK.ru.

объём: 248290 комментариев;

формат: текстовый файл, метка и текст в одной строке;

метки: `NORMAL`, `INSULT`, `THREAT`, `OBSCENITY`, у одного комментария может быть несколько меток;

лицензия: CC BY-NC-SA 4.0.

Метки были переведены в три класса кейса:

`THREAT` или `OBSCENITY`: токсичное;

только `INSULT`: оскорбительное;

`NORMAL`: нейтральное.

Классы несбалансированы: нейтральных около 82%.

Источник: https://www.kaggle.com/datasets/alexandersemiletov/toxic-russian-comments

### Russian Language Toxic Comments

Комментарии с 2ch и Pikabu, 14412 штук, бинарная разметка (токсично или нет). Используется как внешняя тестовая выборка.

Источник: https://www.kaggle.com/datasets/blackmoon/russian-language-toxic-comments

### RuParaDetox

12206 пар: токсичный комментарий и его нейтральный пересказ. Нейтральные пересказы добавлены в обучение как дополнительные нейтральные примеры.

Источник: https://huggingface.co/datasets/s-nlp/ru_paradetox

### Telegram RU Group Chats

948063 сообщения из Telegram-чатов, без разметки. Современный язык Telegram, пригодится для доработки модели.

Источник: https://huggingface.co/datasets/ru-dataset/tg-ru-group-chats

### Golos и Dusha

Аудиодатасеты от Сбера:

Golos: 1240 часов русской речи с расшифровками, используется для проверки распознавания речи;

Dusha: 350 часов речи с метками эмоций, можно использовать для определения агрессии в голосе.

Источник: https://github.com/salute-developers/golos

### Не используются

TextDetox: 98,5% текстов совпадают с комментариями OK.ru;

остальные найденные датасеты на Hugging Face в основном являются копиями OK.ru или имеют ошибки в разметке.

Готовых русских аудиодатасетов с токсичной речью найдено не было.
